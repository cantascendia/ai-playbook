# Learned Rule: 手元の確認サーバーで通った `.htaccess` は Apache では別物 — 実機で 1 回投げるまで「転送は正しい」と言わない

**学到的教训**: robotemi.jp の転送規則 1069 本は、手元の確認サーバー（`_redirects.json` を
JS で引く）では全部通っていた。検証用ドメインの Apache に置いた瞬間、**206 本ちがった**。
どれも「Apache の規則の解釈」を手元のサーバーが真似していなかったもの:

| 手元で見えなかったこと | 起きたこと |
|---|---|
| RedirectMatch / RewriteRule は**復号後の path** に当たる | `^/%e4%bd…$` は日本語スラッグ 64 本に一生当たらない |
| Redirect の転送先は Apache が**自分で符号化**して Location に出す | 符号化済みを書くと `%` → `%25` になり `/ufaq/%25E4…/`（112 本） |
| MergeSlashes（2.4 既定）で `//` は規則に届く前に消える | `/記事//` → `/記事/` の 301（97 本）が 200 で素通り |
| 内部転送先が同じ規則にもう一度当たる | 検索の器 `search/index.html` が `search/[^/]+` に一致して**無限ループ → 500** |
| 末尾スラッシュを無条件に付ける規則 | 存在しない `/404` が `/404/` へ 301、素スラッグが 2 段 |
| `.htaccess` に**出していない型**は静かに 404 | page-bare 4 本が groups に無く、手元では `_redirects.json` 経由で通っていた |
| canonical ホストへの 301 | 検証用ドメインでは**全 URL が本番へ 301**されて検証にならない |
| 絶対 URL のフォントは別オリジン | 検証用ドメインではフォントだけ CORS で落ちてアイコンが全滅 |

## 触发场景

- `.htaccess` / nginx.conf を**生成**していて、確認は手元の Node/Python サーバーでやっている
- 転送規則に日本語（非 ASCII）や `//` や内部転送（`[L]` で別ファイルへ）が入る
- 「検証用ドメイン」に上げるとき（canonical の規則・絶対 URL の資産）
- 台帳から規則を出す generator に「型」の分岐がある

## 应该怎么做

1. **規則の path は復号した UTF-8 で書く。転送先も復号したまま書く。**
   THE_REQUEST から取った値（符号化済み）を Location に出すときだけ `[NE]`。
2. **`//` を見たいなら THE_REQUEST を見る**（`^[A-Z]+\s+([^\s?]*[^\s?/])/{2,}` → `%1/ [R=301,L,NE]`）。
3. **内部転送の器は自分の規則から除外する**（`RewriteCond %{REQUEST_URI} !^/search/index\.html$`）。
4. **末尾スラッシュは「付けた先に頁があるとき」だけ**（`%{REQUEST_FILENAME}/index.html -f`）。
5. **出し忘れは機械で止める**: 台帳の 301 の型 − 出した型 ≠ ∅ なら throw。
6. **検証用に上げるときは deploy がホストを読み替える**（`.htaccess` の canonical と転送先、
   dist に持っている資産の URL）。本番の配信物には触らない。
7. **実機に投げる確認器を 1 本持つ**（`tools/postcheck.mjs` のように台帳全件を fetch して
   status と Location の path を突き合わせる）。手元の PASS では「規則の書き方が正しい」までしか言えない。
8. 準備の順: 手元 → **検証用ドメイン（Apache）** → 本番。検証用を飛ばさない。

## 避免什么

- ❌ 手元の確認サーバーで 301 が通ったから `.htaccess` も正しい、と結論する
- ❌ 規則に `%e3%81…` を書く（復号後に当てるものには一生当たらない）
- ❌ 転送先に符号化済み URL を書く（`%25` に化ける）
- ❌ `[L]` の内部転送先が同じ pattern にもう一度当たらないか確かめずに書く
- ❌ 型ごとに規則を出す generator で、型の一覧を手で持つ（出し忘れが 404 になる）
