# UI 质量清单

逐项过；不适用的跳过，不通过的修完再提交。

## 文本与 i18n
- 用户可见字符串走项目的 i18n 机制（不硬编码在组件里）；日志、注释、调试信息除外
- 带变量的文案用占位符，不拼接；日期/数字/货币用 locale 格式化
- 长文本、其他语言文本不溢出（截断或换行）

## 状态完备
- 空状态有引导，不是一片空白
- 异步操作有加载态；按钮加载/禁用时不能重复提交
- 失败有可读提示和重试入口
- 表单有校验和清晰的错误信息

## 无障碍
- 文字对比度 ≥ 4.5:1（大字 ≥ 3:1）
- 可点击区域 ≥ 44×44 px（移动端 48dp），有焦点/按下反馈
- 图片有 alt（装饰图为空 alt）；图标按钮有可读名称
- 键盘可操作，Tab 顺序与视觉顺序一致
- 尊重系统字体缩放和「减少动态效果」

## 设计一致
- 颜色、字号、间距、圆角引用设计 token / 主题，不写魔法数字
- 优先用项目已有组件，不重复造

## 真实性
- 没有残留的假数据、lorem、写死的示例用户
- 每个可交互元素都连到真实逻辑（占位 UI 不算完成）
- 最小和最大屏宽下布局都不崩
